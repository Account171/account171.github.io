## Preview locally

1. Clone this repository and open the folder in VS Code.
2. Open `index.html` in any web browser (double-click it, or right-click it in VS Code's Explorer and choose **Reveal in File Explorer / Finder**, then open it).
3. After editing and saving, refresh the browser to see your changes.
